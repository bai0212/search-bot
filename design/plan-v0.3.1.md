## 2. 操控台标记规则（§1 定案）

**左键容器**：切换运输起点（蓝框），再左键同一容器取消。

**右键容器**（状态机，按当前容器标记循环）：
1. 当前容器是「收集目标」→ **取消收集**（清空绿框）。
2. 当前容器是「运输终点」→ 改为「收集目标」，并**清空所有运输终点**（起点保留）。
3. 其它情况（无标记 / 是起点）→ 移除该位置旧点位后设为「运输终点」（橙框）。

> 收集目标与运输终点不共存；收集目标与起点可共存（不同容器）。

## 3. 频道系统（§9 定案）

**目标**：操控台用「频道」组织机器人，避免一个操控台同时控制多个机器人导致的绑定混乱。

### 3.1 数据结构（操控台 NBT）
- `Channels`：ListTag，每项 `CompoundTag{ Name:string, RobotId:UUID(可缺省) }`。
- `CurrentChannel`：int，当前频道下标。
- 初始（新操控台）：`Channels=[{Name:"频道01"}]`（一个空频道），`CurrentChannel=0`。

### 3.2 交互
| 操作 | 效果 |
|------|------|
| shift 右键机器人 | 把机器人绑到**第一个空频道**，命名为下一个「频道NN」；若绑定后无剩余空频道，追加一个新空频道（始终保持一个备用空频道） |
| shift + 滚轮 | 切换当前频道（上一个/下一个） |
| shift 右键空气 | 打开**频道管理 GUI** |
| 右键空气 | 循环切换**当前频道**机器人的模式 |
| 左键容器 | 设置当前频道机器人的运输起点 |
| 右键容器 | 当前频道机器人的标记状态机（§2） |

### 3.3 频道管理 GUI
- 显示频道列表（名称 + 是否绑定机器人）。
- 可：切换当前频道、当前频道机器人模式循环、频道改名、主动添加新频道。

## 4. 模式系统（§3 定案）

枚举 `RobotMode`：`FOLLOW(跟随)` `EXPLORE(探索)` `COLLECT(收集)` `TRANSPORT(运输)` `STANDBY(待命)`。

模式循环（右键空气）：`跟随 → 探索 → [收集(若已设收集目标)] → [运输(若已设运输点位)] → 待命 → 跟随…`。

| 模式 | 注册 Goal |
|------|-----------|
| FOLLOW | ReturnToCharge → FollowOwner → 路过收集 |
| EXPLORE | ReturnToCharge → CollectItems(主动) → FollowOwner |
| COLLECT | ReturnToCharge → CollectGoal |
| TRANSPORT | ReturnToCharge → TransportGoal |
| STANDBY | ReturnToCharge（低电仍返航充电），无移动目标 |

---

## 5. 运输模式规则（§4 定案）

- **纯最近邻遍历**所有运输点位（起点/终点一视同仁），每点位一轮只访问一次，访问完重置。
- 在每点位执行：起点=搬入背包，终点=搬入容器。
- **不做**「背包有货就去终点/无货就去起点」的路由分支。
- 停留时长：
  - 起点 = `DWELL_START = 10` tick（0.5 秒）。
  - 终点 = `DWELL_END = (起点数 × DWELL_START) / 终点数` tick（向下取整，至少 1）。
- 起点空跳过、终点满跳过；全跳过则原地等 2 秒重扫。

---

## 6. 收集模式规则（§5 定案）

- 源容器选择：**就近**（距目标容器最近的有物品容器）。
- 机器人背包满 → 必须返回目标容器卸货。
- 目标容器满 → 机器人在目标容器附近**原地不动**（等待）。
- 范围内无可收集容器 → 原地等 2 秒重扫。

---

## 7. 机器人核心（§8 定案）

- 新物品 `robot_core`（机器人核心），进创造栏。
- **组装必选**：组装台新增「核心」槽位（第 11 个槽），`canAssemble()` 要求核心非空。
- 核心持有 `RobotId`（UUID，存在核心物品 NBT）：首次组装时若无 id 则生成并写回核心。
- 组装：机器人 NBT 的 `RobotId` = 核心的 `RobotId`。
- 拆解：核心还原回槽位并**保留其 RobotId**，重新组装仍是同一机器人（操控台绑定不断）。
