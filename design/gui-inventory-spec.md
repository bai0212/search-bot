# 机器人仓库（背包）GUI 界面描述（供美术 AI 参考）

> 用途：给负责 GUI 美术（界面纹理 / 配色 / 图标美化）的 AI 提供机器人仓库界面的完整结构、尺寸和当前实现方式。

---

## 一、这个 GUI 是做什么的

「机器人仓库」是玩家 **空手右键机器人** 打开的背包界面（对应代码 `client/screen/RobotInventoryScreen.java` + `menu/custom/RobotInventoryMenu.java`）。

它分成左右两半：

- **左半**：机器人自己的背包（多少格由机器人决定）+ 玩家背包 + 快捷栏，还有一条电量显示。
- **右半**：一个「物品过滤」面板，用来限制机器人**只能拿 / 不能拿**某些物品（黑白名单）。

---

## 二、界面尺寸

| 项目 | 值 |
|------|-----|
| 界面总宽 | 256 像素 |
| 界面总高 | 动态 = `max(116 + 机器人背包行数×18, 181)` 像素 |
| 左侧背包区 | 左半（0 ~ 176 像素宽） |
| 右侧过滤面板 | 右半（176 ~ 256，宽 80 像素） |

界面在屏幕居中显示（`leftPos` / `topPos` 决定左上角，下文坐标相对界面左上角）。

---

## 三、左侧背包区（功能逻辑，别改坐标）

### 机器人背包槽位
- 从 x = 8、y = 18 开始，每格 18×18。
- 第 r 行第 c 列：x = 8 + c×18，y = 18 + r×18（最多 10 行）。

### 玩家背包 + 快捷栏
- 位置随机器人背包行数下移：
  - 机器人背包底部 = 18 + 行数×18
  - 玩家背包首行 y = 机器人背包底部 + 14
  - 玩家背包 3 行：x = 8 + 列×18，y = 首行 + 行×18
  - 快捷栏 1 行：x = 8 + 列×18，y = 首行 + 58

### 电量显示（在玩家背包标题那一行右侧）
- 电量条：x = 120、y = 玩家背包标题 y，宽 48、高 8。
- 左侧先画电量数字「当前/最大」，再画电量条（背景深灰 `0xFF2A2A2A`，前景颜色按比例：<20% 红、<50% 黄、否则绿）。

## 四、右侧「物品过滤」面板（新功能）

面板整体从 x = 176 开始，宽 80 像素，深色背景（与左半同底色）。

### 面板标题
- 文字「物品过滤」，x = 178、y = 4，橙色 `0xFFFFAA00`。

### 名单模式按钮（点击循环切换）
- 位置：x = 178、y = 18，宽 76、高 18。
- 三个状态循环：**无过滤 → 黑名单 → 白名单 → 无过滤**。
- 显示文字与颜色：

| 状态 | 显示 | 文字颜色 |
|------|------|---------|
| 无过滤 | 无过滤 | 浅灰 `0xFFCCCCCC` |
| 黑名单 | 黑名单 | 红 `0xFFFF6666` |
| 白名单 | 白名单 | 绿 `0xFF66FF66` |

- 含义：黑名单 = 机器人**不拿**下面槽位里的物品；白名单 = 机器人**只拿**下面槽位里的物品；无过滤 = 什么都拿。

### 忽略后缀开关（点击切换开/关）
- 位置：x = 178、y = 40，宽 76、高 18。
- 显示「忽略后缀:开」或「忽略后缀:关」。
  - 开 = 绿 `0xFF66FF66`，关 = 浅灰 `0xFFAAAAAA`。
- 含义：「开」时只看物品类型（比如只要是「铁剑」就算匹配，不管附魔/耐久）；「关」时连附魔、耐久、NBT 都一起比较。

### 过滤物品槽位（放你想限制的物品）
- 共 **12 格**，2 列 × 6 行：
  - 列 x：`178`、`196`
  - 行 y：`66`、`84`、`102`、`120`、`138`、`156`
- 把物品拖进这些格子里，就是你要黑白名单限制的物品。

## 六、当前实现方式（美术 AI 要改的东西）

**这个界面是「代码填充 + 贴图」混合的**：

- 背景：代码用 `fill` 填一层半透明深灰，再 `blit` 贴上 `robot_inventory.png`（256×256，当前只提供标题栏和边框装饰）。
- 槽位底：代码逐个 `fill` 画出来的（浅灰外框 + 深灰内底），不是纹理。
- 右侧面板的按钮和文字：纯代码画。

美术 AI 可以做的事：

1. **重新画 `robot_inventory.png`**（保持 256×256）——把左半的背包区背景、边框、右侧过滤面板的底和分区都画进纹理里，替换掉现在的纯色填充。
   - 文件路径：`src/main/resources/assets/search_bot/textures/gui/robot_inventory.png`
2. **画按钮贴图**：右侧「名单模式按钮」「忽略后缀开关」的图标化（现在只是纯色块 + 文字）。
3. **画图标**：黑白名单、忽略后缀各配一个小图标。

> 注意：第三节、第四节的坐标（槽位位置、按钮位置）是**功能逻辑**（决定点哪里、物品放哪格），美术美化时**不要改坐标**，只改「视觉外观」（纹理 / 颜色 / 图标），否则会破坏点击和物品放置。
