# 机器人操控台 GUI 界面描述（供美术 AI 参考）

> 用途：给负责 GUI 美术（界面纹理 / 配色 / 图标美化）的 AI 提供操控台界面的完整结构、尺寸和当前实现方式。

---

## 一、这个 GUI 是做什么的

「机器人操控台」是玩家 **shift + 右键空气** 打开的一个频道管理界面（对应代码 `client/screen/RobotControllerScreen.java`）。

它把操控台里存的所有「频道」列成一行行，让玩家：

- 看每个频道叫什么名字、是什么模式、绑了哪些机器人；
- 右键模式按钮给某个频道切模式；
- 拖拽机器人方块，把机器人拖到别的频道（改绑定）或拖到界面外（解绑）；
- 点 × 标记删除频道（退出界面后才真正删除）；
- 点 + 号添加新频道。

---

## 二、界面尺寸

| 项目 | 值 |
|------|-----|
| 界面总宽 | 240 像素 |
| 界面总高 | 244 像素（最多容纳 8 个频道） |
| 顶部标题栏 | 高 15 像素（y = 0 ~ 15） |
| 频道列表区起始 y | 24（第一行频道顶部） |
| 每行频道高 | 24 像素 |
| 底部留白（放 + 号） | 28 像素 |

界面在屏幕里居中显示（原版 GUI 的 `leftPos` / `topPos` 决定左上角，下文所有坐标都是相对界面左上角的偏移）。

---

## 三、每一行频道的内容（从左到右）

一行频道高度 24px，内部元素横向排布如下（x 为相对界面左边缘的偏移）：

| 元素 | x 位置 | 宽 × 高 | 说明 |
|------|--------|---------|------|
| 频道名称 | 8 ~ 62 | 54×（文字） | 文字，例如「频道01」 |
| 模式按钮 | 62 ~ 102 | 40×16 | 显示模式前两个字，例如「收集」 |
| 机器人方块 | 从 108 开始 | 每个 48×18，间隔 4 | 显示机器人名字，最多 2 个，超过显示「+N」 |
| 删除按钮 × | 224 ~ 236 | 12×12 | 红色 ×，点击变撤回箭头 ↺ |

行内元素垂直居中（相对该行顶部）：
- 频道名文字：y + 8
- 模式按钮：y + 4
- 机器人方块：y + 3
- × 按钮：y + 6

---

## 四、列表下方的 + 号

- 位置：最后一行频道**下方**，水平居中（x = 界面中心 − 8）。
- 尺寸：16 × 16。
- 作用：点击添加一个新频道。

## 六、交互行为（美术 AI 只需知道，不需要改逻辑）

1. 点击频道名 → 切到该频道（当前频道名变橙色）。
2. **右键**模式按钮 → 该频道切下一个模式（模式有：跟随 / 探索 / 收集 / 运输 / 待命，按钮只显示前两个字）。
3. **拖拽**机器人方块 → 拖到某行 = 改绑该频道，拖到界面外 = 解绑；拖拽时方块变亮、并在鼠标处跟一个名字小标签。
4. 点击 × → 该频道出现灰色**虚线框**、× 变成**绿色撤回箭头 ↺**；再点撤回恢复；**关闭界面后**才真正删除。
5. 点击 + → 添加新频道。

## 七、当前实现方式（美术 AI 要改的东西）

**现在整个界面是纯代码画的**（`GuiGraphics.fill` 填色块 + `drawString` 画文字），**没有背景纹理图片**，所以看起来就是一堆灰色方块。

美术 AI 可以做的事（按价值排序）：

1. **画一张 GUI 背景纹理 PNG**（推荐 256×256，或直接 240×244），替换掉纯色背景填充，让界面有质感/边框。
   - 放到 `src/main/resources/assets/search_bot/textures/gui/` 下。
   - 代码里用 `ResourceLocation` 引用并 `blit` 绘制（需要改 `RobotControllerScreen.renderBg`）。
2. **画按钮/图标**：×（删除）、↺（撤回）、+（添加）、每个模式的图标（跟随/探索/收集/运输/待命）作为小贴图。
3. **重新配色**：给出更统一、好看的配色方案，替换第五节的颜色常量。

> 注意：布局坐标（第三节、第四节）和交互（第六节）是功能逻辑，美术美化时**不要改坐标和交互**，只改「视觉外观」（纹理 + 颜色），否则会破坏拖拽/点击的判定。
