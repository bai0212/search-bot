# 搜索机器人 v0.1.1 更新日志

**发布日期**：2026-07-10

## 🔧 Bug 修复

### 组装台
- **修复了组装后机器人拿不出界面的问题**
  - 原因：按钮点击只在客户端执行，服务端不知道背包里多了物品
  - 解决：新增网络包 `AssemblerActionPacket`，客户端点击按钮后通知服务端执行组装/拆解

### 机器人实体
- **修复了机器人无法放置的问题**
  - 原因：Forge 1.20.1 的生物实体必须注册属性（血量/移速/跟随距离），否则无法生成
  - 解决：注册 `EntityAttributeCreationEvent`，改用 `EntityType.create()` + `level.addFreshEntity()` 稳定生成

## 🏗️ 代码重构

### 客户端 / 服务端分离
- 渲染器、屏幕 GUI 全部移入 `client/` 包，标记 `@OnlyIn(Dist.CLIENT)`
- 服务端事件移入 `server/` 包
- 主类 `SearchBotMod` 仅保留通用注册逻辑，确保联机时服务端不会加载客户端代码
