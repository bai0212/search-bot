# 搜索机器人 v0.1.4 更新日志

**发布日期**：2026-07-10

## 🔧 Bug 修复

### 机器人完全不工作（不跟随、不探索）
- **根因：能量存储默认值为 0**
  - `EnergyStorage` 构造后内部 `energy` 字段默认为 0
  - `tick()` 中机器人一动就调用 `extractEnergy(1, false)`，触发 `syncEnergy()`，把实体同步数据 `DATA_ENERGY` 也刷成了 0
  - `FollowOwnerGoal.canUse()` 和 `CollectItemsGoal.canUse()` 都判断 `getEnergy() <= 0`，于是 AI 目标全部拒绝启动
  - 解决：**在实体构造器中初始化能量为 10000 并同步**

### 区块重载后机器人罢工
- **根因：`readAdditionalSaveData()` 只加载了数据，没有重新注册 AI 目标**
  - `Mob` 构造器里调用的 `registerGoals()` 只注册了 `FloatGoal`
  - 重新进入游戏/重载区块后，机器人只剩一个 `FloatGoal`，不会跟随也不会收集
  - 解决：加载 NBT 后调用 `determineModeAndRegisterGoals(pos, false)`，保留已保存的模式并重新注册对应 AI

### 模式检测接口优化
- `determineModeAndRegisterGoals(BlockPos, boolean detectMode)` 新增 `detectMode` 参数
  - `true`：新放置时根据位置重新检测跟随/探索模式
  - `false`：区块重载时保留原有模式，只重新注册 AI
